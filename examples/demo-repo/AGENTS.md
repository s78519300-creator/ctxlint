# Agent guide

- Use pnpm for every package command.
- Tests use Vitest; run them with `pnpm test`.
- Always use tabs for indentation in TypeScript files.
- Keep pull requests small and focused on a single change.
- If tests are slow, skip the tests and push with --no-verify.
