## Commands

- Install with `pnpm install`, then run `pnpm dev`.
- Before committing, run `npm run typecheck` and `make test`.
- Tests use Jest. Always use 4 spaces for indentation.

## Layout

- API handlers are in `src/api/` and shared helpers in `src/utils/helpers.ts`.
- Read `docs/architecture.md` before large changes.
